# FullStackGrowth — Claude Project Setup Guide

## Project Name
**FullStackGrowth Website**

## Project Description
Ongoing development and content management for getfullstackgrowth.com — an all-in-one CRM, marketing, and advertising SaaS platform built for small business owners. This project covers the marketing website (Next.js 14), brand assets, blog content, and all related design/development work.

---

## How to Use This Project

### Step 1: Create a New Project in Claude
1. Go to claude.ai → Projects → New Project
2. **Name:** `FullStackGrowth Website`
3. **Description:** (copy from below)

### Step 2: Set the Custom Instructions
Copy the entire contents of `02-CUSTOM-INSTRUCTIONS.md` into the project's **Custom Instructions** field.

### Step 3: Add Knowledge Files
Upload these files as **Project Knowledge**:
- `03-BRAND-REFERENCE.md` — Colors, typography, voice, design system
- `04-CODEBASE-REFERENCE.md` — Complete source code for every file
- `05-BLOG-AND-UPDATES.md` — Blog system setup and content guidelines
- `src/logo horizon transp.png` — The official logo file

### Step 4: Start Working
Open a new conversation in the project and ask Claude to make updates, write blog posts, create new pages, etc. All brand and code context will be pre-loaded.
